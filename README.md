# Medical Dashboard

A full-stack **Medical Dashboard** project built with:
- **Backend:** Spring Boot + MongoDB
- **Frontend:** React + Vite

## Features (Work in Progress)
- Patient registration with duplicate email check
- Doctor search by hospital
- Appointment booking system
- User authentication (planned)

## Tech Stack
- **Backend:** Spring Boot, MongoDB
- **Frontend:** React, Vite
- **Build Tools:** Maven, npm

## Development Status
This project is **still under development**. Features and structure may change as work progresses.  
Feel free to explore the code, but note that not all functionality is complete yet.
